Cache Cleaner (Shizuku)
1. Buat repository publik di GitHub, unggah seluruh isi folder ini (termasuk folder .github).
2. Buka tab Actions, tunggu workflow "Build APK" selesai.
3. Unduh artifact "cache-cleaner-apk", ekstrak, pasang app-debug.apk.
4. Pasang dan aktifkan Shizuku, buka aplikasi, beri izin, tekan "Bersihkan Cache".
